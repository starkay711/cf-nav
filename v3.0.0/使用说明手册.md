## 1. 项目简介

cf-nav 是一个部署在 Cloudflare Workers 上的**个人导航主页**，特点：

- **单文件**：整个项目只有一个 `worker.js`，无需构建、无需依赖。
- **Apple 风格 UI**：浅色/深色/跟随系统三种主题，毛玻璃卡片。
- **管理后台**：网页端可视化配置背景、字体、时钟、快捷链接、分类、搜索引擎等。
- **多设备同步**：配置存于 Cloudflare KV，任何设备访问都是同一份配置。
- **PWA**：可"安装"到桌面/手机主屏幕，离线缓存静态壳。

## 3. 部署步骤（新人必读）

### 3.1 准备工作
- 一个 Cloudflare 账号（https://dash.cloudflare.com）。
- 本文件夹中的 `worker.js` 文件内容。

### 3.2 创建 KV 命名空间
1. 登录 Cloudflare Dashboard。
2. 左侧菜单 → **Workers & Pages** → **KV**。
3. 点击 **Create namespace**，名称填 `NAV_KV`（名称可自定，但绑定变量名必须为 `NAV_KV`）。
4. 创建完成后记下该命名空间。

### 3.3 创建 Worker
1. 左侧菜单 → **Workers & Pages** → **Create** → **Hello World Worker**（模板任选）。
2. 给 Worker 起名（例如 `cfnav`），点击 **Deploy** 先部署一次默认代码。
3. 进入该 Worker → **Edit code**（编辑器）。
4. 删除编辑器中默认代码，**把 `worker.js` 的全部内容粘贴进去**。
5. 点击 **Deploy** 保存部署。

### 3.4 绑定 KV
1. 在 Worker 页面 → **Settings** → **Variables**（或 **Bindings**）。
2. 找到 **KV Namespace Bindings** → **Add binding**。
3. 变量名填：`NAV_KV`（必须完全一致）。
4. 选择 3.2 中创建的命名空间 → 保存。
5. 回到编辑器再次 **Deploy**（绑定后需重新部署生效）。

> ⚠️ 如果未绑定 `NAV_KV`，访问站点会显示一个**安装引导页**（setup guide），按页面提示完成绑定即可。

### 3.5（可选）配置背景图环境变量
1. Worker → **Settings** → **Variables** → **Environment Variables** → **Add variable**。
2. 变量名：`NAV_BG_URL`，值：图片 URL（例如 `https://example.com/bg.jpg`）。
3. 保存并重新部署。
4. 该变量会**覆盖**管理后台设置的背景，适合用 CDN 图床统一管理背景。

### 3.6 验证部署
- 访问 `https://<你的worker域名>/` → 应看到导航页。
- 访问 `https://<你的worker域名>/admin` → 应看到管理后台登录/初始化页。

## 4. 初始化：创建管理员账号

首次使用需创建管理员：

1. 访问 `/admin`。
2. 页面检测到尚无管理员时，会显示**初始化表单**。
3. 填写用户名、密码（必要时填邀请码，见 8.5）。
4. 提交后即创建管理员并自动登录。

> 密码使用 **PBKDF2 + 随机盐** 哈希后存入 KV，明文不落地。

## 6. KV 存储键说明

| KV 键 | 内容 |
|-------|------|
| `config` | 导航配置 JSON（标题、背景、字体、时钟、快捷链接、分类、引擎、自定义 CSS 等） |
| `admin` | `{ username, passwordHash, salt }` 管理员凭据 |
| `reg_config` | `{ mode, inviteCode }` 注册模式与邀请码 |
| `bg_image` | 上传的背景图（base64 data URL） |
| `visits` | `{ count }` 访问计数 |
| `session:{token}` | `{ username, expires }` 登录会话，带 KV TTL（7 天） |
| `login_fail:{username}` | `{ count, until }` 登录失败限流记录 |

## 8. 管理后台使用指南

访问 `/admin` 并登录后进入仪表盘。左侧分区如下：

### 8.1 外观（Appearance）
- **背景**：五种类型切换
  - 默认（纯色跟随主题）
  - 颜色（自选纯色）
  - 渐变（CSS 渐变字符串）
  - URL（外链图片）
  - 上传（本地图片，≤5MB，存 KV）
  - 附加：背景模糊开关、遮罩透明度滑杆。
- **主题 & 显示**：主题模式（浅/深/跟随系统）、站点标题、是否在导航页显示管理入口。
- **字体设置**：全局字号（px）、字体族、字体颜色、粗体开关。
- **🕐 时钟 / 日期 / 标题**：见 8.1.1。
- **🎨 自定义 CSS**：注入任意 CSS 到导航页，保存即生效。

#### 8.1.1 时钟 / 日期 / 标题 自定义
对 **时钟（时间）**、**日期**、**标题（问候语）** 三个元素分别可设置：
- **显示**：勾选框，取消则隐藏该元素。
- **大小**：字号，单位 rem。
- **字重**：100~800（极细→特粗）。
- **位置**：左对齐 / 居中 / 右对齐。
- **字体**：跟随全局 或 指定字体族。
- **颜色**：取色器或手输十六进制，留空用默认。

**时钟额外项：**
- **款式**：24小时含秒 / 24小时不含秒 / 12小时含秒 / 12小时不含秒。

**标题（问候语）额外项：**
- **问候语文字**：按 7 个时段（凌晨/清晨/上午/中午/下午/傍晚/晚上）分别自定义文字；留空则该时段用默认问候语。

### 8.2 快速访问（Quick Links）
- 顶部一排图标链接。
- 添加/编辑/删除；图标自动从网址抓取 favicon。
- 登录状态下，导航页可直接**拖拽**排序。

### 8.3 分类与网址（Categories）
- 每个分类是一组网站卡片。
- 分类内可添加/编辑/删除网址。
- 登录状态下，导航页分类内卡片可**拖拽**排序。
- 导航页每个分类自带**筛选输入框**，输入关键字即时过滤该分类卡片。

### 8.4 搜索引擎（Engines）
- 管理搜索引擎列表（id / 名称 / URL 前缀）。
- 设置默认引擎。
- 导航页搜索框左侧下拉可切换引擎。

### 8.5 设置（Settings）
- **修改密码**：输入新密码保存（留空不修改）。
- **注册模式**：关闭 / 开放 / 邀请码。选邀请码时需设置邀请码。
- **访问统计**：显示累计访问次数（来自 `/api/visits`）。
- **重置配置**：把 `config` 恢复为默认（危险操作，慎用）。

> 每个分区修改后需点击该区对应的**保存**按钮才会写入 KV。

## 9. 导航页功能说明

- **时钟区**：大号时间 + 日期（如 `2026年9月26日 星期六`）+ 时段问候语；样式由后台"时钟/日期/标题"配置驱动。
- **搜索框**：
  - 左侧下拉切换搜索引擎。
  - 输入时弹出**搜索建议**（匹配本地快捷链接与分类站点的名称/描述/URL，最多 8 条）。
  - 输入网址形式（如 `example.com`）直接回车可跳转。
- **快速链接**：顶部图标行，登录后可拖拽排序。
- **分类卡片**：毛玻璃卡片网格；每分类有筛选框；登录后可拖拽排序。
- **主题切换**：右上角按钮在浅/深之间切换（跟随系统时按系统偏好）。
- **管理入口**：若后台开启"显示管理入口"，页面有入口跳转 `/admin`。
- **PWA**：支持安装到主屏幕；Service Worker 对静态壳做缓存优先策略。
- **访问计数**：每次打开导航页调用 `/api/visits` 累加。

## 10. 常见问题 FAQ

**Q1：访问站点显示安装引导页？**
A：说明 Worker 未绑定 `NAV_KV`。按 3.2–3.4 完成绑定并重新部署。

**Q2：忘记管理员密码怎么办？**
A：到 Cloudflare Dashboard → Workers & Pages → KV → 选择绑定的命名空间 → 删除键 `admin`。然后重新访问 `/admin` 走初始化流程创建新管理员。（此操作不会丢失 `config` 配置。）

**Q3：背景图不显示？**
A：依次检查——① 是否设置了 `NAV_BG_URL`（它会覆盖后台背景）；② 后台背景类型与值是否正确；③ 上传图是否 ≤5MB。

**Q4：部署后报 `escAttr is not defined`？**
A：说明 worker 代码不是最新版。请用本文件夹 `worker.js` 的完整内容重新粘贴部署。

**Q5：拖拽排序没反应？**
A：拖拽排序仅在**登录状态**下启用。请先登录管理后台再回导航页操作。

**Q6：修改了配置但导航页没变？**
A：① 确认在后台点了该区"保存"；② 导航页有 PWA 缓存，硬刷新（Ctrl+F5）或清除站点数据后重试。

**Q7：访问统计不增加？**
A：统计依赖导航页调用 `/api/visits`。若用广告拦截/隐私插件可能拦截该请求；也可直接 GET `/api/visits` 手动验证。

## 11. 安全机制说明

- **密码哈希**：PBKDF2（SHA-256，迭代加盐），KV 中不存明文。
- **会话**：登录签发 token，存 KV `session:{token}`，TTL 7 天；退出即删除。
- **登录限流**：同一用户名连续失败 5 次锁定 5 分钟（`login_fail:{username}`）。
- **CORS**：API 响应带 CORS 头；OPTIONS 预检返回 204。
- **XSS 防护**：所有动态内容输出前经 `esc` / `escAttr` 转义；URL 经 `safeUrl` 白名单校验（仅 http/https 或裸域名）。
- **写操作鉴权**：所有 PUT/POST 配置类接口均需有效会话。

## 12. 备份与迁移

**备份配置：**
- 登录后 `GET /api/config` 返回完整配置 JSON，保存为文件即可。
- 或在 KV 命名空间中导出 `config`、`bg_image` 键值。

**迁移到新 Worker：**
1. 新 Worker 粘贴同一份 `worker.js`。
2. 新建/复用 KV 命名空间并绑定 `NAV_KV`。
3. 把备份的 `config`（及可选 `bg_image`、`admin`）写入新 KV。
4. 部署即可，配置与账号一并迁移。
